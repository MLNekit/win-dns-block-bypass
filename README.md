# 🛡️ DNS-Block-Bypass

Интерактивный CMD-скрипт для быстрой установки, настройки и управления службой **AdGuard Home** в Windows, а также автоматического переключения DNS-серверов на сетевых адаптерах.

## ✨ Основные возможности

* 🚀 **Установка и удаление службы** AdGuard Home в один клик.
* 🌐 **Быстрая настройка DNS (127.0.0.1)** на выбранных сетевых адаптерах (Wi-Fi, Ethernet).
* 🔄 **Мгновенный сброс DNS в DHCP** при удалении или по запросу.
* ⚡ **Управление службой:** запуск, остановка, перезапуск и проверка статуса порта 53.
* 🔗 **Автоматическое определение порта** веб-панели из `AdGuardHome.yaml` и ее открытие в браузере.
* 🧹 **Очистка кэша DNS** Windows (`ipconfig /flushdns`).
* 🔒 **Настроенные DNS upstream-серверы** с поддержкой DNS-over-HTTPS и DNSSEC.
* 🤖 **Маршрутизация DNS-запросов для AI-сервисов** через отдельный upstream `dns-ai.ru`.
* ⚙️ **Включенное кэширование DNS** и анонимизация IP-адресов клиентов.

## 🌐 Веб-панель AdGuard Home

После запуска службы панель управления доступна по адресу:

`http://127.0.0.1`

Данные для входа:

* **Логин:** `admin`
* **Пароль:** `12345678`

Рекомендуется сменить пароль после первого входа. В текущем конфиге панель слушает порт `80` на всех сетевых интерфейсах (`0.0.0.0`) и работает без HTTPS. Не открывайте доступ к панели из интернета; ограничьте его доверенной локальной сетью или настройте HTTPS и сетевые правила.
